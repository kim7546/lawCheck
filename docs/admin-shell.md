# Admin 기본 화면

FO와 같은 주소의 `/admin`에서 관리자 기본 화면을 제공합니다. 로컬 주소는 `http://127.0.0.1:5173/admin`입니다. FO 빌드에 포함되며 SPA 경로로 직접 접속하거나 새로고침할 수 있습니다.

- 관리 홈, FO 사용자 관리, Office 사용자 관리 메뉴를 제공합니다.
- 메뉴 선택은 URL 해시에 남겨 새로고침·뒤로가기를 지원합니다.
- 현재는 화면 구성만 구현했습니다. 사용자 API 호출, 실제 회원 정보 표시·수정, 관리자 로그인·권한 기능은 연결하지 않았습니다.
- 실제 관리 기능을 연결할 때는 관리자 인증과 서버 권한 검사를 먼저 적용해야 합니다. 일반 Office 회원 로그인이나 공통 코드 관리 권한을 Admin 권한으로 간주하지 않습니다.

사용자가 제공한 원본 PNG 로고를 `apps/fo/public/brand/aiqaver-admin.png`에 복사했습니다. FO·Office·Admin은 지정된 공통 심볼을 파비콘으로 사용하며 각 화면의 전체 로고는 구분합니다. FO의 데스크톱 사이드바 접기 상태는 브라우저 로컬 저장소에 유지하고 모바일 메뉴는 독립적으로 열고 닫습니다.

FO 사이드바가 접히면 별도의 펼치기 아이콘은 숨기고 로고를 진입점으로 사용합니다. 마우스를 올리는 것만으로는 펼쳐지지 않으며, 로고 클릭 또는 Enter·Space로 펼칩니다. 열린 상태는 유지되며 접기 버튼으로 닫습니다. 데스크톱 너비 전환과 모바일 슬라이드에 280ms 모션을 적용하며 `prefers-reduced-motion` 설정에서는 모션을 제거합니다.
