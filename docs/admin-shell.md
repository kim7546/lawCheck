# Admin 독립 서비스

관리자 화면은 `apps/admin`에서 별도로 빌드·실행합니다. 로컬 주소는 `http://127.0.0.1:5175/`입니다. FO 빌드에는 관리자 화면을 포함하지 않습니다. 실행·권한·배포·IntelliJ 설정은 [관리자 안내](admin.md)를 참조하세요.

- 운영 요약, 사용자 관리, 공통코드 관리, BO 메뉴 관리 메뉴를 제공합니다.
- 메뉴 선택은 URL 해시에 남겨 새로고침·뒤로가기를 지원합니다.
- 공통 API의 `/api/v1/admin`에 연결하며 별도의 관리자 로그인과 권한 검사를 적용합니다.
- 일반 Office 회원 로그인이나 공통 코드 관리 권한을 Admin 권한으로 간주하지 않습니다.

관리자 로고는 `apps/admin/public/brand/aiqaver-admin.png`에 있습니다. FO·Office·Admin은 지정된 공통 심볼을 파비콘으로 사용하며 각 화면의 전체 로고는 구분합니다. Admin의 기본 스타일과 문서 제목·검색 제외 메타데이터도 독립 앱에 포함합니다.

FO 사이드바가 접히면 별도의 펼치기 아이콘은 숨기고 로고를 진입점으로 사용합니다. 마우스를 올리는 것만으로는 펼쳐지지 않으며, 로고 클릭 또는 Enter·Space로 펼칩니다. 열린 상태는 유지되며 접기 버튼으로 닫습니다. 데스크톱 너비 전환과 모바일 슬라이드에 280ms 모션을 적용하며 `prefers-reduced-motion` 설정에서는 모션을 제거합니다.
