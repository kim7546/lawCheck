# 데이터베이스 한글 논리 스키마

Prisma 모델과 PostgreSQL 테이블·컬럼에 동일한 한글 논리명과 설명을 적용합니다. DB 도구에서는 테이블 및 컬럼의 설명(Comment)에서 확인할 수 있습니다.

현재 `reviewer_` 테이블은 없으며 Office 회원은 `expert_*` 테이블을 사용합니다. 사무소 배정형 검증 테이블은 별도 업무 모델로 유지합니다. `_prisma_migrations`는 Prisma가 관리하는 배포 이력 테이블입니다.

오픈 전 정리 migration은 아이디·변호사 상세·가입 동의가 모두 없는 구형 회원과 연결된 검증 답변·선택·읽음·커뮤니티 데이터를 삭제합니다. 검증 요청 원문과 현재 가입 정보가 있는 회원은 유지합니다. 이전 단일 답변 컬럼과 로그인 쿠키 호환은 제거했습니다.

## 변호사 회원 상세 (expert_lawyer_profiles)

변호사 선택 회원은 상세 정보 입력 여부와 관계없이 회원당 1개 행을 생성합니다. 미입력 값은 NULL이며 이후 동일 행을 갱신해 정보를 보완합니다.

| 컬럼                  | 한글 논리명·설명                                       | 필수 |
| --------------------- | ------------------------------------------------------ | ---- |
| `account_id`          | 전문가 회원 식별자                                     | 필수 |
| `mobile_phone`        | 휴대전화 번호: 구분 기호를 제거한 숫자                 | 선택 |
| `registration_number` | 변호사 등록 번호: 앞자리 0을 보존하는 문자열           | 선택 |
| `issue_number`        | 변호사 신분증 발급번호: 자격 검증 완료를 의미하지 않음 | 선택 |
| `office_name`         | 소속 법무법인 또는 사무소명                            | 선택 |
| `address`             | 사무소 주소                                            | 선택 |
| `office_phone`        | 사무소 대표전화: 구분 기호를 제거한 숫자               | 선택 |
| `created_at`          | 생성 일시                                              | 필수 |
