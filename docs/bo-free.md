# BO Free 기본 기능

- 로그인·회원가입 후 메인은 대시보드입니다.
- 메뉴는 대시보드, 검증요청 게시판, 커뮤니티입니다.
- 대시보드는 최신 검증요청 5건과 커뮤니티 베스트글 5건을 표시합니다.
- 베스트글은 전체 기간 답글 수 내림차순, 동률이면 등록일·ID 내림차순으로 선정합니다. 답글이 없는 글도 표시합니다.
- 검증 상태는 로그인한 답변자의 진행 상태이며 기존 검증 시작·완료 기능을 유지합니다.
- 커뮤니티는 로그인한 답변자들이 공유합니다. 게시글 제목은 200자, 본문은 20,000자, 답글은 5,000자까지 작성할 수 있습니다.
- 게시글은 최신순, 답글은 등록순이며 각각 20개씩 페이지를 나눕니다.
- 작성자와 요금제는 서버에서 결정합니다. 작성자 이메일·비밀번호 등은 커뮤니티에 공개하지 않습니다.
- 요금제는 `FREE`, `PRO`, `BUSINESS`로 저장하며 기존 및 신규 계정의 기본값은 `FREE`입니다. 이번 구현은 Free 기본 기능이며 유료 결제·요금제 변경 기능은 포함하지 않습니다.

배포 시 `npm run db:migrate`로 `202609250001_free_community` migration을 적용하고 API를 다시 빌드·시작합니다.
