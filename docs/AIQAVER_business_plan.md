# AIQAVER.com 사업계획서 v0.1

## 1. 사업 개요

**서비스명:** AIQAVER  
**도메인:** aiqaver.com  
**브랜드 의미:** AI · QUESTION · ANSWER · VERIFY

AIQAVER는 사용자가 먼저 AI에게 질문하고, AI가 생성한 답변을 해당 분야의 실제 전문가가 검증·보완할 수 있도록 연결하는 **AI 답변 검증 플랫폼**이다.

첫 번째 사업 분야는 **법률**이다. 민사·형사·가사·노동·부동산 등 법률적 문제가 발생한 사용자는 변호사를 찾기 전에 검색엔진이나 생성형 AI를 먼저 이용하는 경우가 많다. AIQAVER는 이 흐름을 활용하여 다음과 같은 새로운 사용자 경험을 제공한다.

```text
질문 → AI 답변 → 전문가 검증 → 추가 질문 → 전문가 연결
```

---

## 2. 핵심 사업 아이디어

기존 생성형 AI 서비스의 가장 큰 문제 중 하나는 사용자가 **AI 답변이 실제로 맞는지 판단하기 어렵다**는 점이다. 특히 법률처럼 전문성과 책임이 중요한 분야에서는 AI가 제공한 답변을 그대로 신뢰하기 어렵다.

AIQAVER의 핵심은 다음 한 문장이다.

> **AI가 답하고, 사람이 검증한다.**

사용자는 AI를 통해 빠르게 기본 정보를 얻고, 필요할 경우 실제 전문가에게 답변 검증을 요청한다. 전문가는 질문자가 이미 AI를 통해 정리한 질문과 답변을 검토하기 때문에 더 효율적으로 잠재 고객과 접촉할 수 있다.

---

## 3. 1차 오픈 목표

1차 서비스에서는 **질문자와 답변자 모두 무료**를 원칙으로 한다. 초기 단계에서는 매출을 최대화하기보다 다음을 우선한다.

- 질문 데이터 확보
- 사용자 유입 확보
- 전문가 공급자 확보
- AI 답변 검증 수요 검증
- 광고 기반 운영 가능성 확인

### 질문자 경험

질문자는 회원가입 없이 사이트에 접속한다. ChatGPT와 유사한 화면에서 법률 질문을 입력한다. AI는 먼저 해당 질문이 법률 질문인지 판별하고, 법률 질문인 경우에만 답변을 생성한다.

AI 답변 하단에는 다음 기능이 표시된다.

> ⚖ 변호사에게 검증받기

검증 요청을 누르면 이름, 이메일, 추가 질문을 입력한다. 등록된 변호사가 답변을 검증하면 질문자는 이메일을 통해 결과를 확인한다.

---

## 4. 답변자 정책

초기 답변자는 **변호사 중심**으로 시작한다. 답변자는 무료로 회원가입할 수 있다.

| 구분 | 1차 오픈 정책 |
|---|---|
| 변호사 가입 | 무료 |
| 질문 수신 | 무료 |
| 답변 작성 | 무료 |
| 프로필 등록 | 무료 |
| 사무실 연락처 표시 | 무료 |
| 검증 답변 노출 | 무료 |

초기에는 변호사에게 비용을 청구하지 않는다. 대신 변호사는 AIQAVER를 통해 법률 질문을 가진 잠재 고객에게 접근할 수 있다.

## 5. 질문자 서비스 흐름

```text
AIQAVER.com 접속
↓
로그인 없이 질문
↓
AI가 법률 질문인지 판별
↓
법률 질문인 경우 AI 답변 생성
↓
AI 답변 표시
↓
[변호사에게 검증받기]
↓
이름 / 이메일 / 추가 질문 입력
↓
검증 신청
↓
등록 변호사에게 전달
↓
변호사 검증 답변 작성
↓
질문자 이메일 알림
↓
AIQAVER 재접속
↓
AI 답변 하단에 변호사 검증답변 표시
```

사용자에게는 **AI 사용 경험을 최대한 방해하지 않는 것**이 중요하다. 따라서 1차 오픈에서는 회원가입을 먼저 요구하지 않는다.

---

## 6. 1차 수익모델

1차 런칭의 주요 수익모델은 **광고**다. 사용자가 AI 답변을 보는 질문 사이트에 광고 영역을 구성한다.

예시:

```text
AI 답변
↓
관련 광고
↓
변호사 검증 CTA
```

또는 PC 화면에서는 오른쪽 사이드 영역에 광고를 배치할 수 있다.

```text
┌──────────────────────┬──────────────┐
│ AI 질문 / 답변 영역  │ 광고 영역    │
│                      │ 광고 영역    │
└──────────────────────┴──────────────┘
```

초기 광고 수익의 목표는 큰 매출이 아니라 **AI API 비용과 기본 운영비 일부 보전**이다.

---

## 7. 왜 초기에는 무료인가

초기부터 질문자에게 결제를 요구하면 질문 데이터 확보 속도가 떨어질 가능성이 높다. 변호사에게도 초기부터 가입비나 리드비를 부과하면 공급자 확보가 어려워진다.

따라서 초기에는 양쪽 모두 무료로 운영하여 다음 선순환을 만든다.

```text
질문자가 많아짐
↓
변호사가 참여할 이유 증가
↓
검증 답변 증가
↓
서비스 신뢰도 상승
↓
질문자 증가
```

## 8. 핵심 자산

AIQAVER의 장기적 핵심 자산은 AI 모델 자체가 아니다. OpenAI를 포함한 여러 LLM 모델은 다른 기업도 사용할 수 있다.

AIQAVER의 핵심 자산은 시간이 지나면서 축적되는 다음 데이터다.

- 실제 사용자 질문
- AI 최초 답변
- 전문가 검증 결과
- AI 답변 수정 내용
- 추가 질문
- 전문가의 실제 의견

즉 단순 Q&A 데이터가 아니라 **AI 답변 + 전문가 검증 데이터**가 축적된다.

---

## 9. 장기 데이터 전략

시간이 지나면 다음을 분석할 수 있다.

- 어떤 질문이 많이 발생하는가
- AI가 어떤 분야에서 자주 틀리는가
- 변호사가 어떤 부분을 자주 수정하는가
- 사용자가 어떤 답변에서 검증을 요청하는가
- 어떤 질문이 실제 상담으로 연결되는가

이 데이터는 향후 AIQAVER의 자체 AI 품질 개선과 전문분야 확장에 활용할 수 있다.

---

## 10. 법률에서 시작하는 이유

법률 질문에는 다음 특징이 있다.

- 질문의 중요도가 높다.
- AI 답변을 그대로 믿기 어렵다.
- 실제 전문가 검증의 가치가 크다.
- 답변 이후 실제 상담 수요가 발생할 수 있다.
- 민사·형사·가사·노동·부동산 등 질문 영역이 넓다.

따라서 **QUESTION → ANSWER → VERIFY**라는 AIQAVER의 개념을 검증하기에 적합하다.

---

## 11. 향후 확장 전략

AIQAVER는 법률에만 머무르지 않는다. 플랫폼의 기본 구조는 특정 전문직에 종속되지 않는다.

```text
사용자 질문 → AI 답변 → 전문가 검증
```

확장 가능한 분야는 다음과 같다.

| 분야 | 전문가 |
|---|---|
| 법률 | 변호사 |
| 세무 | 세무사 |
| 회계 | 회계사 |
| 특허 | 변리사 |
| 노무 | 노무사 |
| 부동산 | 공인중개사 |
| 입시 | 입시 전문가 |
| 교육 | 교사·강사 |
| IT | 개발 전문가 |
| 창업 | 창업·경영 전문가 |

## 14. 1차 오픈 성공 기준

1차 오픈에서 매출액을 핵심 KPI로 잡지 않는다. 가장 중요한 지표는 다음 흐름이다.

```text
방문자 → 질문 → AI 답변 → 검증 요청 → 전문가 답변 → 사용자 재방문
```

| KPI | 의미 |
|---|---|
| 질문 생성 수 | 사용자가 실제 사용하는가 |
| 법률질문 비율 | 유입 품질 |
| AI 답변 완료율 | 제품 안정성 |
| 검증 요청률 | 핵심 기능 수요 |
| 변호사 응답률 | 공급자 활성도 |
| 평균 검증시간 | 서비스 품질 |
| 검증 결과 조회율 | 이메일 재방문 |
| 재질문율 | 사용자 가치 |
| 광고수익 / AI비용 | 초기 경제성 |

## 15. 1차 런칭 전략

초기에는 기능을 많이 만드는 것이 목표가 아니다. 하나의 핵심 경험이 제대로 작동해야 한다.

> 법률질문을 한다 → AI가 답한다 → 변호사가 검증한다.

1차 런칭에서는 다음에 집중한다.

- AI 질문
- AI 답변
- 변호사 회원가입
- 검증 요청
- 변호사 검증
- 이메일 알림
- 광고

결제, 복잡한 추천, 실시간 채팅, 화상상담, 리뷰시스템 등은 이후로 미룬다.

AIQAVER를 단순히 “AI 법률 상담 서비스”로 정의하면 확장성이 떨어진다.

브랜드 관점에서는 다음과 같이 정의한다.

> **AIQAVER는 AI가 생성한 답변을 실제 전문가가 검증하는 Q&A 플랫폼이다.**

첫 번째 Vertical은 법률이다.

```text
AIQAVER
├─ Legal / 변호사
├─ Tax / 세무사
├─ Patent / 변리사
└─ Education / 입시 전문가
```

## 19. 핵심 한 문장

> **AIQAVER는 사용자가 AI에게 먼저 질문하고, AI가 생성한 답변을 실제 전문가가 검증·보완하도록 연결하는 AI 답변 검증 플랫폼이다. 법률 분야에서 시작하여 초기에는 질문자와 전문가 모두 무료로 운영하고 광고를 기반으로 이용자·질문·전문가 데이터를 확보한 뒤, 구독 서비스와 다양한 전문분야로 확장한다.**
